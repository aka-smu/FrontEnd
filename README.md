Commit Types
Type	Description<br>
✨ Feat	새로운 기능 구현
🐛 Fix	버그 수정
✏️ Rename	파일, 폴더, 컴포넌트 등의 이름 변경
🔥 Remove	불필요한 파일, 이미지, 코드 등의 삭제
💄 Style	코드 포매팅, 세미콜론 등 코드 스타일 변경
📱 Design	UI/UX 디자인 및 화면 구성 변경
♻️ Refactor	기능 변경 없이 코드 구조 및 로직 개선
✅ Test	테스트 코드 추가 및 수정
📝 Docs	README 등 문서 작성 및 수정
🔧 Chore	.gitignore, 기타 프로젝트 관리 작업
⚡️ Perf	성능 개선
⚙️ Setting	빌드, 패키지, 환경 설정 등 프로젝트 설정 변경
